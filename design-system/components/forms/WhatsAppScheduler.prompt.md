Self-contained scheduling form: name, service, modality, period. Builds a live message preview and opens `wa.me/<phone>` with it URL-encoded on click. No email, no storage, no backend.

```jsx
<WhatsAppScheduler phone="5521971008336" />
```

This is the site's one mandatory interactive component — every service page and the Contact page must surface it (inline on Contact, as the primary CTA target elsewhere).
