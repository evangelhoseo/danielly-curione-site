Pill-shaped call-to-action button in three weights: mustard-filled primary, terracotta-outline secondary, neutral ghost.

```jsx
<Button variant="primary">Agendar pelo WhatsApp</Button>
<Button variant="secondary">Conhecer atendimentos</Button>
```

Use `primary` for the single main action per screen (usually WhatsApp scheduling). `secondary` for the paired action beside it. `ghost` for low-emphasis inline links inside panels.
